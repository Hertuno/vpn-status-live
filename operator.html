Рассылка клиентам

Три кнопки → вставить в Telegram (или куда пишешь). После отправки закрой issue #1.

  1. DNS без рекламы
  2. Статус + пуши (не Telegram)
  3. Семейный тариф

1) DNS

Можно включить фильтр рекламы через DNS — занимает пару минут.

Инструкция: https://hertuno.github.io/vpn-status-live/dns.html

В VPN укажите DNS:
94.140.14.14
94.140.15.15

Потом переподключитесь. Телевизор, телефон и компьютер начнут получать «чистый» DNS, пока включён VPN.

Если какой-то нужный сайт вдруг не откроется — напишите точный адрес.
Запасной ключ из подписки работает как раньше.

2) Статус и пуши

Если узел не отвечает, Telegram может тоже не открыться. Смотрите статус без VPN:
https://hertuno.github.io/vpn-status-live/

Пуши на телефон (не через Telegram):
https://ntfy.sh/vpn-hertuno-alert-7f3a9c2e
Откройте ссылку → Subscribe / Подписаться.

Запасной ключ из подписки — второй сервер.

3) Семья

Появился семейный тариф: один счёт на весь дом (до 8 устройств), два сервера, статус и оповещения при сбоях, фильтр рекламы.

Цена: ваш текущий годовой × 1.7 (выгоднее двух отдельных подписок).

Подробности: https://hertuno.github.io/vpn-status-live/family.html

Если дома уже несколько человек — напишите, переведём и выдадим ключи под устройства.

Почта (2 минуты)

ntfy.sh → Account → подтвердить email → Access token.
GitHub → Settings → Secrets → Actions: NTFY_TOKEN, NTFY_EMAIL.
Потом Actions → Test notify channels → Run.

Подробности: EMAIL.md
