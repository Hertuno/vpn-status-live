DNS без рекламы

Пока включён VPN, запросы имён сайтов можно гнать через фильтр — меньше рекламы и трекеров на телефоне, ПК и ТВ.

Сейчас — за 2 минуты (клиент сам)

В приложении VPN укажите DNS AdGuard:

  • 94.140.14.14
  • 94.140.15.15

Amnezia: сервер → протокол → поле DNS → оба адреса → сохранить → переподключиться.

Hiddify: настройки профиля / Remote DNS → те же адреса (или DoH https://dns.adguard-dns.com/dns-query) → обновить подписку → переподключиться.

Проверено: doubleclick / analytics → 0.0.0.0; google.com открывается. Отчёт проверки

Запросы имён уходят на публичный фильтр AdGuard. Сайты, которые «пропали», напишите админу — добавим исключение после перехода на свой фильтр на сервере.

Надёжнее — фильтр на вашем VPN-сервере

На каждом VPN-VPS (нужен root), один раз:

curl -fsSL https://raw.githubusercontent.com/Hertuno/vpn-status-live/main/install-adguard.sh | bash

Потом в Amnezia/Hiddify DNS клиентов = GATEWAY туннеля (часто 10.8.0.1 или 10.66.66.1), не 1.1.1.1.

Так запросы имён остаются на вашем сервере, а не у стороннего фильтра.
