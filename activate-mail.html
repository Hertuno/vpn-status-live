Включить почту при сбоях

Письма из GitHub Actions до ящика часто не доходят. Нажми кнопку из браузера — FormSubmit пришлёт Activate на hertuno@yandex.ru.

  1. Нажми кнопку выше
  2. Открой Яндекс → Входящие и Спам
  3. Письмо FormSubmit → ссылка Activate
  4. Готово: монитор сможет слать письма при DOWN/UP
